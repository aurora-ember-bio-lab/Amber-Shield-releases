VectorizedDB

Semantic search
over your events.

Amber Shield uses pgvector to store and search event embeddings. Every CVE, every log line, every secret finding gets a 768-dimensional vector via Ollama's nomic-embed-text:v1.5.

🔍 Semantic search

Find events by meaning, not just keywords. "Show me everything like that SQL injection" — vector similarity finds it.

🧠 Local embeddings

Ollama runs on 127.0.0.1:11434. Embeddings never leave your machine.

📊 pgvector index

IVFFlat index with cosine distance. 768d vectors, lists = 100. Production-ready SQL.

💾 Memory fallback

MemoryVectorStore for offline/demo. Same API, zero infrastructure.

PostgreSQL + pgvector schema

CREATE EXTENSION vector; CREATE TABLE event_vectors ( id UUID PRIMARY KEY, embedding VECTOR(768), source TEXT NOT NULL, severity TEXT NOT NULL, message TEXT NOT NULL, metadata JSONB, ts TIMESTAMPTZ DEFAULT NOW() ); CREATE INDEX idx_embedding ON event_vectors USING ivfflat (embedding vector_cosine_ops) WITH (lists = 100); -- Semantic search query: -- SELECT id, message, 1 - (embedding <=> $1::vector) AS similarity -- FROM event_vectors -- ORDER BY embedding <=> $1::vector -- LIMIT 10;
